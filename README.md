# recursos-informaticos-MAR

## Objetivo
Página web sencilla con el **horario del grupo DAM-1ºB** y una sección de **recursos informáticos** útiles (documentación, tutoriales y herramientas). El proyecto se ha creado como práctica para aprender a usar GitHub: repositorios, commits, ramas, pull requests, resolución de conflictos, issues, releases y GitHub Pages.

## Estructura del proyecto
```
recursos-informaticos-MAR/
├── index.html   → Tabla del horario y sección de recursos
├── style.css    → Estilos de la página
├── README.md    → Documentación del proyecto
├── .gitignore   → Archivos que Git debe ignorar
└── LICENSE      → Licencia del proyecto
```

## Instrucciones
1. **Ver la web publicada:** https://manuel456722.github.io/recursos-informaticos-MAR/
2. **Verla en local:** descarga el repositorio (*Code → Download ZIP*) y abre `index.html` en el navegador.
3. **Colaborar:** crea una rama a partir de `main`, haz tus cambios y abre una *pull request* hacia `main` para que se revisen antes de integrarlos.

## Archivo .gitignore
El archivo `.gitignore` indica a Git qué archivos o carpetas no debe registrar en el repositorio, como archivos del sistema (`.DS_Store`, `Thumbs.db`), configuraciones del editor (`.vscode/`), archivos temporales o dependencias. Así el repositorio solo contiene los archivos importantes del proyecto.
